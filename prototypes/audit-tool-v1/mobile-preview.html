Designer notes (not shown to operators):
All frames are live iframes at 375px, scaled to ~64% display size using CSS transform. Pointer events are disabled on iframes; click the bezel to navigate to the full page.
Each screen uses a responsive single-file layout with media queries at 375px / 768px / 1280px. Mobile bottom nav (5 tabs) is present on all screens except this gallery page (desktop-only utility).
Mobile tier: all main screens are Tier 2 (responsive, no clipping). Run-history table in trends.html uses sticky-first-column horizontal scroll. Fix-pipeline track in fixes.html uses overflow-x:auto. No page-level horizontal overflow at 375px on any screen.
