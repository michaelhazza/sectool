How fix requests work

When you click "Send for fixing" on an issue, this tool creates a GitHub issue in your repository with a pre-written description of the problem and suggested fix. Your team reviews and merges the fix. Once merged, the next scan confirms whether the problem is gone.

This requires a GitHub token (AUDIT_GITHUB_FIX_TOKEN) with permission to create issues in your repo. The token never has access to read or write code.

What you see if fix-sending is not set up
Fix-sending is not configured
To send issues for fixing, set the AUDIT_GITHUB_FIX_TOKEN environment variable to a GitHub personal access token with "issues:write" permission for this repository. The token never needs access to read or write code.

Until that is set up, use "Copy fix instructions" on any finding to paste a ready-made description into a GitHub issue manually.
